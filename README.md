# 📊 Sales Data Exploratory Data Analysis (EDA)

## Project Overview
This project explores a Superstore sales dataset using Python to understand sales performance, profitability, data quality, and business patterns.

## Objectives
- Explore dataset structure and data types.
- Check missing values and duplicate records.
- Identify potential outliers using the IQR method.
- Calculate descriptive statistics.
- Visualize sales and profit trends.
- Perform statistical hypothesis testing.
- Generate business insights and recommendations.

## Tools & Technologies
- Python
- Pandas and NumPy
- Matplotlib and Seaborn
- SciPy
- Git and GitHub

## Project Structure
- `data/raw/` — Raw dataset
- `outputs/` — Analysis results
- `outputs/charts/` — Data visualizations
- `reports/EDA_Report.md` — Detailed EDA report
- `task_01_load_data.py` to `task_08_business_insights.py` — Analysis scripts
- `requirements.txt` — Required Python libraries

## How to Run
Install the required libraries:

```bash
python -m pip install -r requirements.txt
```

Run the scripts from the project root directory:

```bash
python task_01_load_data.py
python task_02_data_overview.py
python task_03_data_quality.py
python task_04_outlier_analysis.py
python task_05_statistical_analysis.py
python task_06_visualizations.py
python task_07_hypothesis_testing.py
python task_08_business_insights.py
```
